📚 Sinopsis Kursus

Communication System Fundamentals memperkenalkan pelajar kepada konsep sistem komunikasi. Kursus ini merangkumi prinsip komunikasi, teknik modulasi analog dan digital, multiplexing, dan medium penghantaran. Konsep pensampelan, kuantisasi, dan teknik pengekodan talian dalam menjadikan isyarat maklumat serasi dengan sistem digital dijelaskan sebelum kajian Pulse Code Modulation (PCM). Ia juga mendedahkan pelajar kepada asas transmisi data dan kod komunikasi.

🔵 Bab 1 — Formula Asas

1. Signal-to-Noise Ratio (SNR)
SNR = P_signal / P_noise
SNR(dB) = 10 × log₁₀(S/N)
P_signal = kuasa isyarat (W) | P_noise = kuasa hingar (W)
Contoh: P_s=100mW, P_n=1mW → SNR=100 → SNR(dB)=10×log₁₀(100)=20dB
2. Noise Factor & Noise Figure
F = SNR_in / SNR_out
NF(dB) = 10 × log₁₀(F)
F = Noise Factor (linear) | NF = Noise Figure (dB)
Contoh: F=4 → NF=10×log₁₀(4)=6.02dB
3. Frekuensi, Bandwidth & Panjang Gelombang
λ = c / f     (c = 3×10⁸ m/s)
BW = f_high − f_low
Contoh: f=900MHz → λ=3×10⁸/9×10⁸=0.333m=33.3cm

🟢 Bab 2 — Formula Modulasi & PCM

4. Teorem Pensampelan Nyquist
fs ≥ 2 × fm
fs = kadar pensampelan | fm = frekuensi isyarat maksimum
Contoh: fm=4kHz → fs_min=2×4000=8000Hz=8kHz
5. Tahap Kuantisasi
L = 2ⁿ
L = bilangan tahap | n = bilangan bit
Contoh: n=8 → L=2⁸=256 tahap
6. Saiz Langkah & Ralat Kuantisasi
Δ = (V_max − V_min) / L
Qe = ± Δ/2
7. Signal-to-Quantization Noise Ratio (SQR)
SQR(dB) = 1.76 + 6.02n
n = bilangan bit per sampel
Contoh: n=8 → SQR=1.76+6.02(8)=49.92dB
8. PCM Bit Rate
Bit Rate = fs × n
Contoh: fs=8000Hz, n=8 → Bit Rate=64,000bps=64kbps

🔴 Bab 4 — Formula Transmisi Data

9. Bit Error Rate (BER)
BER = Bilangan bit salah / Jumlah bit dihantar
Contoh: 5 bit salah dalam 10,000 bit → BER=5×10⁻⁴
10. Shannon's Channel Capacity
C = B × log₂(1 + S/N)
C=kapasiti(bps) | B=jalur lebar(Hz) | S/N=nisbah linear
Contoh: B=3kHz, SNR=1000 → C=3000×log₂(1001)≈29,900bps
